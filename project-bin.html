树莓派 智能垃圾桶

让一个垃圾桶学会看人

  • 角色核心成员（组装 / 调参 / 测试）
  • 时间2025
  • 工具树莓派 · 传感器 · 舵机 · Python

01 为什么做这个

垃圾桶开盖这件事看起来小，但每次都要用手碰一下，在厨房、医院这类地方就不太舒服。这个项目想验证一件事：用很便宜的硬件，能不能做出「人靠近就自动开」的效果。

我在团队里负责「让它真的跑起来」的那部分：组装、接线、调参、测试——把实验室里能演示的东西，推到能连续运行。

02 我做了什么

  • ✦把整件事拆成三段：识别到来的人 → 触发舵机开盖 → 语音提示状态。每段单独跑通再串联，出问题时能立刻知道卡在哪一段。
  • ✦独立完成硬件组装、线路调试与运行环境配置，从零把设备搭起来。
  • ✦针对识别误差反复调整灵敏度与距离阈值，记录「误开盖」和「不识别」两类错误的分布，先判断是参数问题还是接线问题，再动手改。
  • ✦与组员同步开发进度、对接技术难点，沉淀测试记录与迭代清单，让下一轮改的时候不用重新摸索。

03 结果

最终设备能连续完成「靠近 → 开盖 → 提示」的整套动作，误触发和不出盖的情况比第一版少了很多。

更重要的是方法上的收获：学会了先怀疑接线再怀疑代码，也知道了「改一个参数、跑同一套动作」才叫测试。

04 回头看

硬件和软件最大的差别是「不可复现」——同一个动作，今天好明天坏。所以后来我给每次测试都记下当时的环境和参数，不然改了半天，也不知道是哪一步起的作用。

如果能加预算，我会换更好的传感器，而不是继续在参数上磨。这是做完才明白的：有些问题不是调出来的，是换出来的。
