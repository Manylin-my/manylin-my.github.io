这个 站点本身

从一页长滚动，改成有结构的多页站

  • 角色设计 · 开发 · 内容
  • 时间2026.11 –
  • 工具手写 HTML / CSS / JS · Git

01 为什么做这个

想有一个自己的地方放东西：做过的项目、写了一半的想法、一些没什么用但想记下来的事。用现成模板当然更快，但我想从零搭一次，顺便把课上学的网页和结构知识真的用一遍。

02 我做了什么

  • ✦不套框架，手写 HTML / CSS / JavaScript；四个栏目共享一套样式表，改一处全站生效，加页面只需要写内容。
  • ✦每个页面单独写 title、description 与 Open Graph 信息，栏目页和详情页之间用清晰的内链串起来——这既是给人看的结构，也是给搜索引擎看的结构。
  • ✦视觉上定了一套暖米色 + 衬线标题的编辑部风格，图标用手绘 SVG 代替图片，整站不加载任何外部图片资源。
  • ✦做了移动端断点适配、键盘焦点样式、aria 标签，以及「减少动效」系统偏好的支持。

03 结果

站点从一页长滚动改成了多页结构：现在是四个栏目加四个项目详情页，每个页面有自己的地址，可以被单独分享和收录。用 Git 管版本，每次改动留一条记录，改坏了能退回去。

04 回头看

最大的收获不是学会写 CSS，是理解了「结构先于样式」。一开始所有内容都堆在一个页面里，导航点了不会跳，改一处要动整页；拆成多页之后，每加一个东西只需要动一个地方。

另一个体会是：做得慢一点，反而快。每次只改一处、改完就看一眼实际效果，比一口气改十处再一起排查要省时间。
