拾光箱 交互原型

用箱子收好每一段时光

  • 角色产品定位 · 信息架构 · 交互原型
  • 时间2025 – 2026
  • 形态Web 交互原型（可在线试玩）

01 成果

拾光箱是一个收个人记忆的工具：照片、视频、文字不按月份平铺，而是按「那件事」收进一个个箱子，想看的时候整箱翻开。下面这台手机里跑的是完整原型——注册、建箱子、加素材、翻时间轴、全屏看照片，一条路走得通，不用安装。

  • 13 屏全部可点击
  • 4 条核心流程走通
  • 6 个功能模块
  • 4 个目标用户场景

左边这台手机是真的能点的，不是录屏——按钮、表单、翻页都能操作。建议从「欢迎页」开始，走一遍注册 → 建箱子 → 加素材。

02 为什么做 & 目标

照片躺在相册里是按月份平铺的，一条时间线里混着截图、外卖单、随手拍的云，翻三个月前的一次旅行要一路划过去；发在朋友圈又只是给别人的。中间缺一个位置：只给自己看的、能按「那次旅行」「那个夏天」整块翻回去的地方。

所以我把「箱子」当容器——不是文件夹，是有盖子的、贴了手写标签的收纳盒。目标也很具体：新建一个箱子 → 一天一天往里放东西 → 半年后还能原样翻出来。整理的过程本身要有仪式感，而不是多一个"上传"按钮。

03 我做了什么

  • ✦信息架构：13 屏分成四块——认证流程（欢迎 / 注册 / 登录 / 忘记密码）、核心功能（首页 / 新建箱子 / 添加素材 / 时间轴）、内容展示（当天回忆 / 全屏相册）、辅助（搜索 / 我的 / 设置）。
  • ✦主链路：欢迎 → 注册 → 登录 → 我的箱子 → 新建箱子 → 添加素材 → 回忆时间轴 → 当天回忆 → 全屏相册。每一屏都能点到下一屏，不留断路。
  • ✦「箱子」这个容器：旅行 / 聚会 / 纪念日 / 日常 / 学习五类，建箱时选分类、起名字、挑封面。收纳这个动作要有手感，不能只是填个标题。
  • ✦多媒体时间轴：照片、视频、随记混排在同一条轴上，按天分段，顶部显示共多少张照片、多少段回忆——先让人知道这箱子里装了多少。
  • ✦账号体系做全：注册（手机号 + 验证码 + 两次密码）、登录、忘记密码重设三条路都画完了，不是只做主路径。
  • ✦视觉方向：拟物牛皮纸质感 + 手写体标签，颜色压到米白与棕色系。它得有纸箱子的手感，才配得上「收好每一段时光」这句话。

04 给谁用

定位的时候先想清楚它替谁干活，四个场景都是从自己的动作里推出来的：

  • ✦旅行回忆收纳：一次旅行一个箱子，按天加照片视频、写当天见闻，回来就是一整篇游记。
  • ✦宝宝成长记录：专属箱子按月记，第一次走路、第一次叫妈妈，都是独一份的东西。
  • ✦恋爱纪念日：「我们的故事」一个箱子，约会、节日、礼物按时间排下去，是两个人的时光胶囊。
  • ✦年度回忆录：一年一个箱子，年底翻开就是这一年的总结，比翻相册更有仪式感。

05 回头看

现在最被追问的一句是「箱子和相册到底差在哪」。这说明概念本身要靠界面解释，不能靠文案——下一页我得让它更直白：箱子里装了什么、有多少、怎么翻，第一眼就懂。

另一个还没答案的问题：原型里的数据全是我自己造的演示数据。真实的人会怎么起名、会不会真按事件建箱子、一个箱子放到多少条就嫌烦，我不知道。等有十几个人真用过，第一批要改的多半是「建箱」那一步。

分享入口在原型里留着，但做的时候有意识没往社交上走：能分享的是一箱只读的回忆，不是一条公开动态。一旦能给别人看，整理就变成表演了。
